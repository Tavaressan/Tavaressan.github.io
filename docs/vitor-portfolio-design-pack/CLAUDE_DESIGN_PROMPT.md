# Claude Design Prompt

Prototype one complete, polished journey for the Vitor Tavares software
developer portfolio.

## Creative direction

Think: **engineering drafting table + cinematic wind + sakura + modern
editorial portfolio**.

The reference to *Kaze Tachinu / The Wind Rises* is atmospheric, not
literal. Do not make a fan site.

## Hero

Use the supplied `mp4_vitor_ghibli_sakura_soundless.mp4` as the
full-bleed hero background.

Composition: - figure/person at left; - large sakura tree at right; -
open sky and park in the middle; - falling petals; - Ghibli/16-bit
visual treatment.

Do not put the video inside a card. Do not use a heavy dark overlay. Do
not add the chibi over the video unless clearly subordinate.

Hero content: - SOFTWARE DEVELOPER; - Vitor Tavares; - one short
technical sentence; - VIEW WORK; - subtle scroll indicator.

## Journey

Build:

1.  Cinema / Hero
2.  Paper / Introduction
3.  Drafting Table / Selected Work
4.  Machine / Project Detail
5.  Return to Work

Do not create many disconnected screens first.

## Selected Work

Avoid generic floating cards.

Use editorial technical entries:

``` text
PROJECT 01
ENTERPRISE AGENT PLATFORM
Rust · TypeScript · MQTT · AWS

Multi-agent orchestration for elevator fleet management.
───────────────────────────────────────────────→ OPEN PROJECT
```

Hover/focus reveals a visual preview with a horizontal mask, like a
technical sheet being unrolled.

Click expands into Project Detail using a shared visual element.

## Motion

Use: - Wind for horizontal transitions; - Draft for masks and technical
reveals; - Petal for rare atmosphere; - Flight for subtle depth.

Durations: - 160ms micro; - 280ms short; - 520ms medium; - 900--1400ms
cinematic.

No bounce. No scroll-jacking. No animation on every text line. Respect
reduced motion.

## Visual system

EB Garamond for display. Source Sans 3 for body. JetBrains Mono for
technical metadata.

Light: `#EFE9DD`, `#F7F3EB`, `#2A2420`, `#B86B4A`, `#9C5A3D`, `#6F8D9E`,
`#D9D1C5`.

Dark: `#1C1F25`, `#242830`, `#E6E0D6`, `#D0845E`, `#8AAABB`.

Maximum radius around 3px.

## Avoid

-   SaaS dashboard aesthetic;
-   glassmorphism;
-   giant rounded cards;
-   heavy gradients;
-   constant sakura petals;
-   literal Japanese decorative motifs;
-   excessive Ghibli references;
-   animation for animation's sake.

## Success condition

The first impression should be cinematic. The second should be
technical. The whole experience should feel authored, not templated.
